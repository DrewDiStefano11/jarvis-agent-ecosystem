# Mission Control Activity evidence

Activity renders the existing shared audit collection newest sequence first. Search includes reported summary/event/record/task/actor identifiers; actor and category filters retain their selected scope across refreshes. Unknown actor/task references retain stable identifiers. Category derives from the event-type prefix; the audit contract does not provide a source field. Demonstration is shown only when the payload reports simulated:true; otherwise provenance is explicitly unavailable. Seeded and demo records are never counted as autonomous throughput.

The initial display contains 50 records, expands in batches of 50, and caps at 200. Counts describe matching loaded records, not complete runtime history. Refining filters can inspect other loaded records. Existing AppStore HTTP/snapshot synchronization remains authoritative, with stale/error notice and shared refresh. No polling, new domain state, command authority or event cursor is added.

Native disclosures mount evidence only when opened. Display/copy payloads are bounded to 8,000 characters, with additional depth/node/field/array/string limits and explicit truncation. Sensitive key values and recognized authorization/token/credential patterns are redacted, including quoted JSON inside free text. Summaries/metadata are bounded and sanitized too. React renders text, never HTML. Copy writes exactly the displayed evidence; clipboard failures offer manual selection rather than claiming success. This defense does not replace backend credential-safe record creation or guarantee detection of arbitrary unknown free-text secrets.

Known collection limitation: the compatible existing /api/audit-events endpoint and shared snapshots still return an unpaginated repository audit collection. This PR bounds rendered rows and displayed/copied evidence, not network transfer or the shared collection's memory footprint. Future read pagination must coordinate with the shared snapshot contract and backend owners. No backend changes are imported or proposed here.
